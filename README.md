# lila_smarana

Sanskrit stotram reader app for bhajana reading, organized by spiritual personality.

## Personalities (branches)

| Personality | Status | Content |
|---|---|---|
| Sri Caitanya | Live | Caitanya-stotram (8 daily periods + invocation + benefit) |
| Radha-Krishna | Live | Bhavanasara-Sangraha (BSS) time-of-day reader |
| Manjari Seva | Coming soon | No source data in .vidya yet |
| Srila Prabhupada | Coming soon | No source data in .vidya yet |

## Getting Started

```bash
flutter pub get
flutter run
```
